# 🌕 ルナーランダム（Lunar Random）

月面ビリヤード。往年の『ルナーボール』へのオマージュです。

遊ぶ: https://naway0141-source.github.io/lunar-random/
ゲーム集: https://naway0141-source.github.io/

## ルール

- **STAGE 1 だけ**普通の長方形テーブル（6ポケット）
- **STAGE 2 からは外形が完全ランダム生成**。更新するたびに二度と同じ形は出ません
- ただし「ゲームとして成り立つ変形度」に制限：極端な針状の角や、球が詰まる狭い入り江は生成時に棄却されます
- 全部の的球をブラックホール（ポケット）に落とせばクリア。番号は関係なし
- 手球が落ちたらファウル。手球だけを中央付近に戻して打ち直し

## 操作

- ドラッグ： 向きと強さを決める（ガイド線と、最初に当たる球の進路予測が出ます）
- 離す： ショット
- フリクション： 本家と同じ 0〜255 のスライダ。台の滑り具合が変わります（初期値 32）

## 技術メモ

- ランダム外形は「中心から見て星型になる多角形」を角度・半径の乱数で生成し、辺の長さ・内角・自己交差を検証してから採用
- 物理は円と線分の衝突（壁）＋等質量の弾性衝突（球同士）を 240Hz のサブステップで計算
- 依存ライブラリなし。Canvas 2D + 素の JavaScript の単一 HTML ファイル
- 生成と物理のロジックは Node 上のテストハーネスで検証済み（500シードの生成妥当性、衝突、脱出しないこと）
